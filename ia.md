# Utilisation de l'IA

Un assistant d'intelligence artificielle, **Claude** (développé par Anthropic), a été utilisé dans ce projet pour :

* corriger les erreurs du code (erreurs de compilation, de configuration et de logique) ;
* vérifier la conformité du projet avec l'énoncé du TP (endpoints demandés, format des réponses, bonus, README) ;
* assister la publication du projet sur GitHub (préparation du dépôt et du push).
